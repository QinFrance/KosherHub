# Contributing

Suggest a device, ROM, site, article, topic, or category through the website's Submit page, or open a GitHub issue or pull request.

For device records include the exact model, hardware revision, carrier considerations, and a source. Describe filtering and kosher suitability precisely; do not infer certification from a keypad or a custom firmware image.

ROM contributions should identify the maintainer, exact supported hardware, version, release source, redistribution license, checksum, installation steps, and recovery instructions. Do not commit ROM binaries, credentials, personal information, or copyrighted files you do not have permission to distribute.

Changes to the database require a new migration. Never edit an already applied migration. Validate anonymous access, administrator authorization, and draft privacy when changing backend behavior.

All code contributions are made under the MIT license.
