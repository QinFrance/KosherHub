# Icon assets

- `mark.svg`: original KosherHub K monogram, released with this repository’s MIT license.
- Phone illustrations: original KosherHub illustrations. Palette normalized to blue and achromatic neutrals.
- Interface icons: Google Material Symbols Rounded, Apache License 2.0. Source: https://github.com/google/material-design-icons and https://developers.google.com/fonts/docs/material_symbols . SVG files are served locally; no icon font or external request is needed. Each SVG is modified only to use `currentColor`. The full license is in `MATERIAL-LICENSE.txt`.
- `github.svg`: existing GitHub identifying mark, modified only to use `currentColor`. GitHub is a trademark of GitHub, Inc.; the mark identifies the source-code link.
